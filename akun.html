Super Admin

Kelola Akun Pengguna

Buat, nonaktifkan, dan reset password akun Admin Dinas, Pengawas, dan Ketua KKG Sekolah.

Tambah Akun

Import Akun dari CSV

Unggah file CSV dengan kolom (baris pertama = judul): username,password,role,nama_lengkap,kecamatan,sekolah

• role diisi: admin, pengawas, atau kkg_sekolah.
• Kolom password boleh dikosongkan → sistem membuat otomatis.
• Username yang sudah ada akan dilewati.

Jika diisi, semua akun pada file ini memakai password ini (wajib diganti saat login pertama).

Generate Akun dari Data Master

Membuat akun otomatis dari tab 3_Sekolah & 2_Kecamatan. Akun yang sudah ada dilewati, jadi aman dijalankan ulang. Daftar username & password tersimpan di tab _Kredensial untuk dibagikan.

Kosong = KKG pakai NPSN, Pengawas pakai password acak. Apa pun pilihannya, semua wajib diganti saat login pertama.
